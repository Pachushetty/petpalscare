---
name: New account defaults
description: Product expectation for empty state and avatar behavior on new PetPals customer accounts.
---

New customer accounts should start with no demo bookings and no profile photo until the user adds one. Keep sample records limited to the dedicated demo account, and preserve the existing customer-portal design when fixing these defaults.

**Why:** the user asked that new accounts not show prefilled bookings or an automatically assigned profile photo.

**How to apply:** when changing registration, customer data defaults, bookings, or profile rendering, ensure new accounts remain empty while demo-account examples continue to work.
